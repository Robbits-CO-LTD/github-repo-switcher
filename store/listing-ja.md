# Chrome Web Store 掲載文（日本語）

## 名称

Repo Signal — GitHub Issue Switcher

## 概要

お気に入りのGitHubリポジトリの Issues 一覧を、GitHub画面から1クリックで切り替えます。

## カテゴリ

デベロッパー ツール

## 対応言語

日本語

## 価格

無料

## 詳細説明

### データの取扱い（重要）

Repo Signal は、GitHubのURLから得る `owner/repository`（NWO）という閲覧中のリポジトリ識別子を扱います。Issuesの利用可否と、seedまたは既存の表示用リポジトリの公開・非公開・アーカイブ状態も、表示のために扱います。

お気に入りから除外したNWOと、GitHubページを訪れたことで表示対象に加わったリポジトリ情報は、端末内の `chrome.storage.local` に保存します。通常クリックの移動アニメーションでは、移動元NWO、移動先NWO、レール上の位置、時刻を、そのGitHubタブの `sessionStorage` に保存します。この項目はアニメーションで読み取った後に削除します。作成から10秒を超えた項目は利用せず、次回の読み取り時またはタブを閉じたときに削除されます。

これらのデータをRobbitsまたは第三者へ外部送信することはありません。ローカル設定は変更するまで、拡張機能をアンインストールするまで、またはブラウザのストレージを削除するまで残ります。拡張機能のアンインストールまたはブラウザのストレージ削除で削除できます。

### できること

- GitHubのリポジトリ名とタブの間に、Issues切替レールを表示します。
- 「すべてのリポジトリ」パネルからリポジトリを検索して、Issues一覧を開けます。
- 星ボタンまたは設定画面で、お気に入りに表示するリポジトリを切り替えられます。
- Issuesが無効なリポジトリは表示しますが、移動先としては選べません。

### 単一の目的

お気に入りのGitHubリポジトリの Issues 一覧を1クリックで切り替えることだけです。

### `storage` 権限の理由

NWO、Issuesの利用可否、表示用の公開・非公開・アーカイブ状態は、レールと検索パネルにリポジトリを表示するために使います。お気に入りから除外したNWOは、利用者が選んだ表示設定を次回も反映するために保存します。`sessionStorage` の移動情報は、同じGitHubタブでの短い移動アニメーションのためだけに使います。

### `https://github.com/*/*` へのアクセス理由

`https://github.com/*/*` へのアクセスは、GitHubのリポジトリページ上にIssues切替レールを表示し、そのページのURLから現在のNWOを読み取るためだけに必要です。

### データ利用に関する宣言

申告するデータ種別は「ウェブ閲覧アクティビティ」です。対象はGitHub URL由来のNWOと、そのリポジトリをレールへ表示するための状態に限ります。

Repo Signal はGitHub API、GitHubトークン、Cookie、ページ本文、入力フォームの内容を収集しません。NWO以外の氏名、住所、電話番号、メールアドレスなどを意図して収集することもありません。分析、広告、データ販売、プロファイリング、信用評価または融資目的での利用は行いません。実行時にRobbitsまたは第三者へデータを送信しません。

Repo SignalがChrome Web Storeから受け取る情報は、Chrome Web Store User Data Policy（Limited Use要件を含む）に従って使用します。単一目的以外には利用・転送・販売せず、人が閲覧することもありません。

Repo Signal は外部から取得したコードを実行するリモートコードを使用しません。

### 審査担当者向けの確認手順

1. 拡張機能をインストールします。資格情報は不要です。
2. 公開リポジトリ https://github.com/Robbits-CO-LTD/github-repo-switcher/issues をChromeで開き、リポジトリ名とタブの間に表示されるレールを確認します。
3. 「すべてのリポジトリ」を開き、検索欄でリポジトリを検索します。
4. リポジトリの星ボタンを切り替えます。
5. 設定ボタンからオプション画面を開き、お気に入り設定を確認します。

保存されたデータは、拡張機能をアンインストールするか、ブラウザのストレージを削除すると削除できます。
