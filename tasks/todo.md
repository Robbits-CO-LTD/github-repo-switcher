# Repo Signal 実装計画

## 目的

GitHub のリポジトリ画面に、お気に入りリポジトリを横並びで表示し、各リポジトリの Issues 一覧へ1クリックで切り替えられる Chrome 拡張を作る。

## デザイン方針

- 黒に近い背景、細い境界線、白い文字を基本にする。
- ミントグリーンは現在のリポジトリと操作中の状態だけに使う。
- お気に入り同士を細い線と小さな点でつなぐ「Signal Rail」を署名的な要素にする。
- 外部フォント、過剰な発光、グラデーション、GitHub と無関係なチャート装飾は使わない。
- 狭い画面では折り返さず横スクロールし、キーボードでも操作できるようにする。

## 更新後の初期仕様

- GitHub 標準のリポジトリ名の直下、タブ列の直前に高さ約52pxの横並びバーを1段だけ常時表示する。
- 常時表示は現在地とお気に入りに絞る。初期状態では Issues が有効な全リポジトリをお気に入りにする。
- `すべてのリポジトリ` を押すと、最大幅680px・画面高の最大70%の検索パネルをページ上へ重ねて開く。
- 初期登録は、現在のGitHub認証でアクセスできるすべてのリポジトリとする。
- 設定はこの端末内だけに保存し、外部へ送信しない。
